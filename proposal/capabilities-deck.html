R1 — Reports Remediation

Fix the Reports module, completely

We'll audit against the defect log and the codebase patterns — not just patch the listed items but close anything we find.

Defect categories:

  • Filter wiring (Time Period, Warehouse, Category, Status)
  • Internationalization gaps (numbers, dates, strings)
  • Options API → Composition API migration
  • Console errors and runtime warnings

Our commitment

"All defects found" — not a fixed list. If we find more than Meridian logged, we fix them too.

R2 — Restocking Recommendations

Give operations the tool they've been waiting for

The Restocking view will let your operations team set a budget ceiling and receive a ranked purchase order list — per SKU, per warehouse, per supplier.

How it works:

  • Compare current stock to demand forecast
  • Identify at-risk SKUs by warehouse
  • Rank recommendations by urgency
  • Apply budget ceiling, regenerate on change

Data first

We'll validate the existing /api/demand data in Week 1 before building on it. No surprises mid-project.

Fits the existing UI

Built with the same Vue patterns and filters as the rest of the dashboard.
