# Pricing

**RFP Reference:** MC-2026-0417

---

## Pricing Structure

We are proposing a **fixed-fee engagement** for the four required deliverables. Fixed-fee pricing gives Meridian budget predictability and removes the risk of scope creep on a constrained engagement. There are no hourly rates, no not-to-exceed ambiguity, and no surprises at invoice.

---

## Fixed Fee — Required Scope (R1–R4)

| Item | Description | Fee |
|---|---|---|
| R1 | Reports module remediation — all defects in Meridian's log plus any discovered during audit | $12,000 |
| R2 | Restocking recommendations view — backend endpoint + frontend feature | $16,000 |
| R3 | Automated browser test suite — all four critical flows, documented for IT handoff | $8,000 |
| R4 | Architecture documentation — current-state overview, visual diagram, IT-ready | $4,000 |
| **Total** | | **$40,000** |

---

## Optional Items (D1–D3)

These items are scoped separately and can be added to the engagement at kickoff or during delivery, subject to budget availability.

| Item | Description | Fee |
|---|---|---|
| D1 | UI modernization — apply brand guidelines across dashboard | $4,500 |
| D2 | Internationalization — extend i18n to remaining modules (Japanese translations provided by Meridian) | $4,500 |
| D3 | Dark mode — operator-selectable theme via CSS custom properties | $2,000 |
| **D1–D3 combined** | All three desired items | **$9,500** |

**Full engagement (R1–R4 + D1–D3): $49,500**

---

## Payment Terms

- 25% on contract execution
- 25% on delivery of R4 (end of Phase 1)
- 25% on delivery of R1 and R2 (end of Phase 3)
- 25% on final handoff (end of Phase 5)

---

## Assumptions & Exclusions

- Japanese translations for D2 are provided by Meridian. If translation work is required, it will be scoped and priced separately.
- Demand data cleaning (R2 dependency), if required, will be assessed during Phase 1. If the scope exceeds 8 hours, we will present options to Meridian before proceeding.
- Infrastructure, hosting, and third-party licensing costs are not included.
- Any changes to the agreed scope will be handled via a written change order before work begins.
